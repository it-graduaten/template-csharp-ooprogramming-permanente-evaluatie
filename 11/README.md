# Unit testing

Unit testing is een techniek waarmee we individuele componenten van onze applicatie — zoals functies, klassen of methoden — geautomatiseerd kunnen testen. Het doel is om ervoor te zorgen dat elk onderdeel correct werkt, onafhankelijk van andere delen van de applicatie.

*De oefeningen in dit hoofdstuk tellen niet mee voor de score voor permanente evaluatie. Je zal op het examen de vraag krijgen om één of meerdere unit tests te schrijven.*
